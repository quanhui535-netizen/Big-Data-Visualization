# 选做说明：14 个实验是怎么挑的

教材资源包（`D:\zashi\CAD`）里有 4 本书、上百个案例和 notebook。全部做完既不现实，也没有必要；
这里说明**挑选原则、覆盖范围、以及和同类作业（`课程章节复现_Excel图表/`）的工作量对比**。

---

## 一、挑选原则

1. **四本书都要有，且不扎堆**：一级 5 个、二级 3 个、三级 3 个、四级 3 个，避免"只做一本书"；
2. **同一本书内章节分散**：例如三级教材只取了 2.4、4.1、第 6 章，跨"关联规则 / 时间序列 / 特征工程"三个方向，
   而不是把 2.1—2.5 连着做完；
3. **两类迁移都覆盖**：
   - 需求 ①：Excel / WPS / Power BI / SQL 实现的案例 → Python（实验 01—05）；
   - 需求 ②：本身就是 .ipynb 的章节 → 重构为 `.py`（实验 06—14）；
4. **优先选"有完整数据、能跑出结论"的案例**：数据缺失、只有截图没有数据的章节不选；
5. **控制单实验数据体积**：超过 10 MB 的原始文件做确定性抽样并注明，保证仓库可 clone、可复跑。

## 三、工作量对比

| 对比项 | `课程章节复现_Excel图表/`（前期练习） | 本目录（教材实验） |
|---|---|---|
| 主题 | 《Excel 数据可视化》第 2—4 章图表复现 | CDA 四本教材的分析案例迁移 |
| 脚本数 | 约 50 个（一图一脚本） | 14 个（一实验一脚本，单脚本含 4—8 张图） |
| 图片数 | 约 55 张 | 72 张 |
| 结果表 | 少量 | 53 张 CSV |
| 每个交付物 | 一张图 | 图 + 表 + 100 行左右的中文实验报告 |
| 分析深度 | 图形样式复现 | 业务问题 → 数据处理 → 建模/统计 → 结论建议 |

结论：本目录的**图片数量与前期练习相当（略多）**，但每个实验还多了数据清洗、统计检验/建模和文字报告，
所以总工作量与 `课程章节复现_Excel图表/` 同量级，符合"差不多或略少"的要求。
