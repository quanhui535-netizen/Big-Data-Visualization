## 三、快速开始

```bash
# 1. 安装依赖（建议虚拟环境）
pip install -r requirements.txt

# 2. 任选一个实验，进入目录直接运行
cd 02_一级教材_第03章_收入趋势分析
python lab02_revenue_trend.py
```

- 每个脚本**自包含**：只读本目录 `data/` 下的数据，结果写到本目录 `outputs/`；
- 不需要联网、不需要数据库、不需要 Excel / Power BI；
- 输出统一为 `figXX_中文名.png`（160 dpi）和 `tableXX_中文名.csv`（UTF-8-BOM，Excel 双击不乱码）。

### 目录内统一结构

```
NN_级别教材_第XX章_主题/
├── README.md              # 实验报告：教材做法、迁移对照、结果解读
├── labNN_xxx.py           # 主脚本（可一键运行）
├── data/                  # 本实验用到的原始数据（已做体积裁剪）
└── outputs/               # 运行后生成：figXX_*.png、tableXX_*.csv
```

### 统一风格

- 所有图共用 [`common/style.py`](./common/style.py)：微软雅黑/黑体、深蓝 + 橙主色、统一网格与边距；
- 每张图标题、坐标轴、图例均为中文，负号正常显示；
- 脚本不使用 `plt.show()`，保证在服务器/无界面环境也能跑通。

## 五、这个目录想说明什么

1. **工具会变，分析框架不变**：教材里拖透视表、写 DAX、点切片器，本质都是"分组—聚合—比较—下钻"，
   Python 只是把这些动作翻译成 `groupby / pivot_table / merge / 布尔过滤`；
2. **Notebook 不是交付物**：`.ipynb` 适合探索，但不可复跑、不可版本管理、不可被调度；
   重构成 `.py` 后才能"改一个参数跑全流程"，这也是 06—14 号实验统一做的事情；
3. **每个数字都能追溯**：结果表与图同源，README 里的结论都来自脚本真实输出，可逐格核对。
