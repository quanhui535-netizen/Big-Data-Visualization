# 数据来源合规声明

本文件用于说明本项目所用数据的来源、获取方式、授权与使用边界，供教师与评阅人核查。

## 一、数据源

| 项目 | 内容 |
|---|---|
| 数据集名称 | Online Retail Data Set |
| 发布机构 | UCI Machine Learning Repository（加州大学欧文分校） |
| 数据集编号 | 352 |
| 官方页面 | https://archive.ics.uci.edu/dataset/352/online+retail |
| 官方下载地址 | https://archive.ics.uci.edu/static/public/352/online+retail.zip |
| 原始规模 | 541,909 行 × 8 列；时间范围 2010-12-01 至 2011-12-09 |
| 内容说明 | 一家注册于英国的在线零售商在一年内的全部交易流水，含订单号、商品编码、数量、单价、客户编号与国家 |

## 二、获取方式（白名单第 1 类：官方一次性文件下载）

- 通过 UCI 官方静态链接直接下载公开 ZIP 包，解压得到 `Online Retail.xlsx`；
- **未使用** Scrapy、Selenium、requests + 网页解析、模拟登录等任何爬虫或抓取手段；
- 未绕过任何登录、验证码、反爬机制或付费墙；
- 下载动作由脚本 `scripts/01_load.py` 完成，可重复执行、可审计。

## 四、授权与使用边界

- 该数据集在 UCI 页面标注为 **CC BY 4.0**，允许在署名前提下用于研究与教学；
- 本项目仅将数据用于课程作业的分析、建模与可视化展示；
- 原始数据转载需遵循 CC BY 4.0 的署名要求，本项目不在仓库中二次分发原始文件，仅保留下载脚本与校验信息；
- 分析结论仅代表本数据集所反映的经营情况，不代表任何真实企业的最新经营数据。

## 五、分析口径声明

- 销售额口径：`Revenue = Quantity × UnitPrice`，已剔除退货（取消单）、邮费与手工调整行、以及客户标识缺失的游客订单；
- 客户级模型仅覆盖客户编号非空的 391,148 行交易（占清洗后数据的 100%），游客交易单独统计；
- 未做抽样，全部模型基于全量清洗后数据计算，因此不涉及随机种子设定。
